# 开发状态

更新于 2026-09-22。当前为 **3.4.1 开发预览版**，尚未打标签或分发。

## 当前工作

安装器现以需要管理员权限的全机安装为目标，使用 64 位 Program Files、HKLM App Paths 和单一公共开始菜单入口。应用仍为 `asInvoker`，按用户保存的配置与备份不由 MSI 管理，卸载后保留。此前的当前用户预览版需一次性卸载重装，后续全机版本通过大版本升级更新。参阅[安装器说明](../tools/Installer/README.zh-CN.md)和[使用指南](SETUP.zh-CN.md)。

国际服卡片显示所选战网登录区域 EU、US 或 KR，当前配置仍单独显示。切换引擎与配置事务未改。

全机包本地检查已通过：编译零警告、零错误，52 项回归、包验证、七项发布拒绝情形，以及零错误、零警告的完整 ICE 套件。CI 候选来源及安装生命周期验收仍待完成。此前当前用户包的恢复结果，包括管理员对照通过，不能证明新包通过。确切证据及待测项见 [3.4.1 验证](VALIDATION-3.4.1.zh-CN.md)。

## 剩余验收工作

1. 通过源码提交和哈希确定干净的 CI 候选，完成全机安装生命周期，包括升级失败恢复和旧预览版检测。
2. 对最终变更完成基本启动和双语界面检查。已有完整 DPI 与在线往返保留为历史覆盖，仅在应用行为受到影响时扩大重测范围。

从普通桌面通过 UAC 交互安装，再以普通用户启动应用的检查仍待完成。高权限 CI 生命周期测试不能证明这条交互路径。原始 3.4.0 候选的四档 DPI 矩阵和国服 → 欧洲 → 国服往返仍记录于[历史验证](VALIDATION.zh-CN.md)，不宣称完成了新的在线往返。

## 发布约束

仓库保持私有，应用许可证尚未选择。包未签名，依赖 .NET 10 Desktop Runtime x64。原始 3.4.0 私有草稿及文件保持不变。每个分发预览递增三段版本；提升时复制实测 CI 制品，不重新构建。跨显示器、跨电脑及系统策略覆盖仍有限。
