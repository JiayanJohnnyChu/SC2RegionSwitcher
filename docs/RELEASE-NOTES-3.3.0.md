# SC2 Region Switcher 3.3.0 Preview

Windows x64 的星际争霸 II 国服／国际服切换器，使用 WPF。界面支持简体中文和英文，提供可配置安装路径和单一开始菜单入口。

运行需要 **Microsoft .NET 10 Desktop Runtime x64**。准备一套官方 Battle.net 和两套独立游戏安装；国服使用简体中文游戏数据，国际服使用英文。账号登录与游戏启动由官方战网完成。

附件提供当前用户 MSI、便携 ZIP、发布清单及 SHA-256 校验值。MSI 不捆绑 .NET 运行环境。请完整解压便携包，或安装 MSI 后从开始菜单打开 **SC2 Region Switcher**。

该版本为未签名预览版。自动检查覆盖构建、隔离回归及安装包内容，不能替代实机双服在线验证。跨电脑兼容性、完整升级流程及代码签名尚未完成。

本安装器尚无自动升级流程。切换同版本重建包或后续版本前，应正常退出程序并卸载旧安装；用户配置保留。具体配置步骤见仓库 `docs/SETUP.zh-CN.md`。
