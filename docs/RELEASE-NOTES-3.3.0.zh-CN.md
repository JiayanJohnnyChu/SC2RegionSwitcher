# SC2 Region Switcher 3.3.0 预览版

3.3.0 是面向 Windows x64 的历史预览版，采用 WPF 和 .NET 10。该版提供独立的国服与国际服路径、可配置的战网及共享设置位置，并提供英文和简体中文界面。

国服文本与语音使用简体中文，国际服使用英文。界面语言可独立选择。登录和游戏启动在官方战网中完成。运行包需要 Microsoft .NET 10 Desktop Runtime x64。

未签名的分发内容包括当前用户 MSI、便携 ZIP、发布元数据和 SHA-256 校验值。MSI 创建单一开始菜单入口，使用带版本号的应用目录，未包含自动升级处理或降级保护。返回这一历史版本以较新应用的预先移除为前提；用户配置独立保存，卸载时保留。

当前配置步骤见[使用指南](SETUP.zh-CN.md)，后续变化见[更新记录](../CHANGELOG.zh-CN.md)。
