# SC2 Region Switcher 3.4.0 预览版

该候选保留为未发布的私有草稿，安装失败恢复尚未通过验收。

## 变化

- 界面的字体、间距与页面对齐经过调整，国服和国际服使用不同颜色。
- 界面将战网当前配置与所选目标分开显示。
- 安装器引入从 3.3.0 进行当前用户范围的 MSI 升级、稳定应用目录及单一开始菜单入口。
- 发布流程引入版本与源码来源检查，并直接提升原始 CI 候选文件。

界面支持英文和简体中文。国服使用 `zhCN` 游戏数据，国际服使用 `enUS`，界面语言独立设置。配置要求一套战网、两套独立游戏安装及实际共享的 `Variables.txt`。账号登录和游戏服务器选择仍在战网中完成。配置流程记录于[使用指南](SETUP.zh-CN.md)。

## 安装

安装包未签名，运行需要 Microsoft .NET 10 Desktop Runtime x64。MSI 安装要求应用已关闭。配置、语言偏好、备份和恢复记录独立保留。便携运行要求 ZIP 已完整解压。

原始 3.3.0 包没有降级保护。早期手动创建的快捷方式或 App Paths 条目若仍指向已退役目录，需单独核查。

## 验证

[验证记录](VALIDATION.zh-CN.md)标明的确切候选通过编译、52 项回归、包检查、正常安装生命周期检查、100%／125%／150%／200% 双语 DPI 矩阵，以及一次国服 → 欧洲 → 国服在线往返，游戏均正常退出。

失败路径测试未能完整恢复旧安装，因此草稿继续暂缓发布。这一安装器恢复结果与应用内部的语言事务恢复分别处理。跨显示器移动、其他电脑和不同系统策略环境尚未验证。候选原文件保持不变。
