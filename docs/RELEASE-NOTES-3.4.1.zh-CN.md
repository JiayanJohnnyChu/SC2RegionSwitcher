# SC2 Region Switcher 3.4.1 预览版

需要管理员权限的 MSI 已针对验证记录标明的候选通过构建、包检查及托管环境生命周期测试。最终 CI 候选已通过交互式 UAC 迁移及随后以普通用户启动的检查，隔离配置下的基本英文和简体中文设置界面检查已通过。分发范围保持私有。

## 变化

- 国际服目标卡片将 INTERNATIONAL 改为 EU、US 或 KR，表示所选战网登录区域。当前配置仍单独显示，实际游戏服务器在战网中选择。
- MSI 为所有用户安装到 64 位 Program Files，登记 HKLM App Paths，创建单一公共开始菜单入口。安装需要管理员批准，应用以普通用户权限运行。
- 此前的当前用户预览版需一次性卸载重装，后续全机版本通过 MSI 大版本升级更新。产品族 UpgradeCode 保留，全机范围使用新的产品与组件标识。
- MSI 定义与验证元数据已修正，配套独立 ICE 验证和隔离全机生命周期检查。
- 文档提供成对的英文与简体中文版本，便携 ZIP 包含两份 README。

切换引擎、配置事务和独立界面语言设置不变。配置和备份仍按用户保存在 `%LOCALAPPDATA%\SC2RegionSwitcherV2`，不由 MSI 管理，卸载后保留。

## 验证与分发

已标明的全机候选通过托管环境中的安装、维护、升级、升级失败恢复及移除检查。CI 运行 35723586274 的最终候选通过交互式 UAC 迁移及普通用户启动检查。完整托管生命周期结果属于较早的包，其应用源码与 MSI 定义与最终候选相同；最终修订仅涉及文档和测试程序。此前当前用户包的检查与管理员恢复对照不能证明此包通过验收。证据记录于 [3.4.1 验证](VALIDATION-3.4.1.zh-CN.md)。

完整 DPI 矩阵和在线往返仍属于 3.4.0 的历史结果。最终已安装应用通过隔离配置下的基本英文和简体中文设置界面检查，不宣称完成了新的完整 DPI 矩阵或在线往返。跨显示器移动和跨电脑行为仍未验证。

原始 3.4.0 文件保持不变。包未签名，运行需要 Microsoft .NET 10 Desktop Runtime x64。仓库保持私有。原始 3.4.1 包未包含项目许可证，许可与分发材料于 3.4.2 加入。安装与迁移步骤见[使用指南](SETUP.zh-CN.md)。
