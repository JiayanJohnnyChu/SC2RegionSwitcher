# SC2 Region Switcher 3.4.1 开发预览版

需要管理员权限的 MSI 已通过本地构建与包检查，CI 生命周期验收仍待完成。3.4.1 尚未打标签、分发或提升发布。

## 变化

- 国际服目标卡片将 INTERNATIONAL 改为 EU、US 或 KR，表示所选战网登录区域。当前配置仍单独显示，实际游戏服务器在战网中选择。
- MSI 为所有用户安装到 64 位 Program Files，登记 HKLM App Paths，创建单一公共开始菜单入口。安装需要管理员批准，应用以普通用户权限运行。
- 此前的当前用户预览版需一次性卸载重装，后续全机版本通过 MSI 大版本升级更新。产品族 UpgradeCode 保留，全机范围使用新的产品与组件标识。
- 修正 MSI 定义与验证元数据，配套独立 ICE 验证和隔离全机生命周期检查。
- 文档提供成对的英文与简体中文版本，便携 ZIP 包含两份 README。

切换引擎、配置事务和独立界面语言设置不变。配置和备份仍按用户保存在 `%LOCALAPPDATA%\SC2RegionSwitcherV2`，不由 MSI 管理，卸载后保留。

## 验证与分发

新的全机包需要自身的 CI 来源、哈希和生命周期证据。此前当前用户包的检查与管理员恢复对照不能证明此包通过验收。参阅 [3.4.1 验证](VALIDATION-3.4.1.zh-CN.md)。

完整 DPI 矩阵和在线往返仍属于 3.4.0 的历史结果。后续界面检查覆盖修改后的标签，不宣称完成了新的完整在线往返。跨显示器移动和跨电脑行为仍未验证。

原始 3.4.0 文件保持不变。包未签名，运行需要 Microsoft .NET 10 Desktop Runtime x64。仓库保持私有，应用许可证尚未选择。安装与迁移步骤见[使用指南](SETUP.zh-CN.md)。
