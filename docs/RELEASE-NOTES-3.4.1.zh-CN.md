# SC2 Region Switcher 3.4.1 开发预览版

本版正在验证。安装器恢复验收尚未完成，尚无最终候选被提升发布。

## 变化

- 国际服目标卡片将 INTERNATIONAL 改为 EU、US 或 KR，表示所选战网登录区域。当前配置仍单独显示，实际《星际争霸 II》服务器在战网中选择。
- MSI 应用组件采用 HKCU 注册表键路径，并更新组件标识。产品族 UpgradeCode 和稳定应用目录不变。
- 修正 MSI 列定义、旧目录命名及语言中立文件元数据，新增标准验证元数据和不屏蔽规则的独立 ICE 检查。
- 文档提供成对的英文与简体中文版本，便携 ZIP 也包含两份 README。

切换引擎、配置事务和独立界面语言设置不变。

## 验证与分发

本地编译零警告、零错误；52 项隔离回归、包检查和五项发布拒绝情形通过。独立 ICE 套件报告零错误及四条 ICE91 警告，涉及固定当前用户目录假设用于全机安装的情形。标准窗口在 200% 缩放下的基本中英文标签检查通过。

完整在线往返及四档 DPI 结果属于 3.4.0。当前预览版的安装失败恢复仍未解决，参阅 [3.4.1 验证](VALIDATION-3.4.1.zh-CN.md)。

原始 3.4.0 文件保持不变。3.4.1 使用新的三段 MSI 版本，需具备自身的 CI 来源、包哈希和安装证据。安装包仍未签名，运行需要 Microsoft .NET 10 Desktop Runtime x64。配置步骤见[使用指南](SETUP.zh-CN.md)。
