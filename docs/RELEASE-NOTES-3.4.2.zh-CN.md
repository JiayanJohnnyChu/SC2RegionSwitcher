# SC2 Region Switcher 3.4.2 预览版

[首个公开预览版](https://github.com/JiayanJohnnyChu/SC2RegionSwitcher/releases/tag/v3.4.2-preview.1)于 2026 年 9 月 22 日发布，支持通过一个战网客户端切换独立的国服和国际服安装，提供英语／简体中文界面选择、配置验证、备份与恢复。

发布包含全用户 MSI、便携 ZIP、清单和 SHA-256 文件。包未签名，需要 Windows x64 与 .NET 10 Desktop Runtime x64。MSI 安装需要管理员批准，应用以普通用户运行。卸载保留配置和备份。

本次修改将 [MIT 许可](../LICENSE)及[第三方材料](../THIRD-PARTY-NOTICES.zh-CN.md)加入两种包，应用行为不变。CI、发布提升及匿名下载哈希检查通过。[验证](VALIDATION.zh-CN.md)记录发布身份，以及先前安装和界面证据的适用范围。
