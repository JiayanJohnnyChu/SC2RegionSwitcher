# SC2 Region Switcher 3.5.3 预览版

此版本更新界面，并增加已安装的国际服游戏语言选择，适用于通过一个战网客户端使用独立国服和国际服《星际争霸 II》安装的玩家。

- 自适应界面让小窗口中的设置、错误详情和操作仍然可用。设置内容与底部控件对齐，输入框与语言选择框的内部间距保持一致。
- 十一种界面语言与游戏语言独立设置。内嵌 Inter／Noto 字体提供一致的文字显示；精简后的字体子集保留所需字符和字重。
- 国际服可选择已安装的文字／语音组合。修正后的解析能够识别实际安装记录中的语言资源；安装不可用时仍保留已保存的语言偏好。
- 当前地区与语言均符合目标时，不再提供无须执行的重启操作。
- 修正导航、路径编辑后的保存、修复链接与错误翻译。

路径验证、语言原子写入、备份与恢复继续保留。国服使用 `zhCN`，国际服默认 `enUS`。切换前需要完成下载和更新。

未签名的全用户 MSI 和便携 ZIP 需要 Windows x64 与 .NET 10 Desktop Runtime x64。MSI 安装需要管理员批准；应用以普通用户运行。用户配置和备份与应用文件分开保存，卸载后仍予保留。

[验证](VALIDATION.zh-CN.md)记录验证范围与发布验收状态。[设置指南](SETUP.zh-CN.md)说明配置与使用，[第三方声明](../THIRD-PARTY-NOTICES.zh-CN.md)涵盖随附材料。
