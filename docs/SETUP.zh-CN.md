# 配置与使用指南

SC2 Region Switcher 使用一套战网桌面应用和两套独立的《星际争霸 II》安装，切换战网登录区域并修改游戏共享设置中的语言键。当前预览版本为 3.4.2，修订仅涉及许可与分发内容，应用行为不变。验证范围记录于[验证状态](VALIDATION-3.4.2.zh-CN.md)。

## 1. 运行要求

- Windows x64 和 **Microsoft .NET 10 Desktop Runtime x64**。只有开发才需要 .NET SDK。所需的 Windows x64 **Desktop Runtime** 由 [Microsoft .NET 10 下载页](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)提供。
- 一套官方 Battle.net 桌面应用，以及相应区域服务的访问条件。
- 独立安装的国服和国际服游戏，且下载、更新和修复均已完成。
- 游戏实际使用的 `Variables.txt`，当前 Windows 用户须能读写该文件。

切换器不下载游戏数据、不注册账号，也不改变账号使用资格。登录与身份验证在官方战网中完成。

## 2. 游戏安装准备

两套游戏安装需要独立目录，例如：

```text
D:\Games\StarCraft II CN
D:\Games\StarCraft II Global
```

两者不能相同或互相包含。给同一安装换一个名字，或建立指向它的目录链接，都不构成第二套安装。每个游戏根目录须直接包含 `StarCraft II.exe`、`.build.info` 和 `Versions`。

国际服安装要求英文文本与语音，国服安装要求简体中文文本与语音。两者均通过战网安装，顺序不限。最终安装位置需要在确认下载前核验，因为战网可能自动补上 `StarCraft II` 子目录，也可能识别已有安装。指向另一服目录的路径必须在继续安装前修正。

每套安装的验证过程包括从战网启动、确认游戏主界面及正常退出。此过程也会生成共享设置文件。以后在切换器里修改路径，不会搬移游戏或更改战网的安装记录。

首次准备时若缺少所需登录区域，区域请求要求游戏与编辑器已关闭、战网下载已完成且战网已正常退出。下列 PowerShell 命令分别请求同一程序使用指定登录区域。可执行文件路径必须对应实际安装位置，仅所需区域的命令适用：

```powershell
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=CN
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=EU
```

其他国际登录区域值为 `US` 和 `KR`。请求结果由登录界面确认。当前实现使用此参数，兼容性取决于已安装的战网版本。如果参数不被接受，战网区域访问问题必须在配置切换器前解决。切换器会检查两套安装，无法替代这一步首次准备。

## 3. 共享设置文件

共享设置文件位于当前 Windows 用户实际的“文档”文件夹内：

```text
StarCraft II\Variables.txt
```

配置要求使用游戏生成的真实文件，其中应各有一条 `localeidassets` 和 `localeiddata`。文件缺失时，保存设置并正常退出的游戏会话可生成该文件。空白替代文件无法通过检查。

“文档”已移动时，可以在高级设置中选择真实文件位置。经过重解析点的路径会被拒绝，例如部分目录链接或同步文件夹。把文件复制到别处，并不能改变游戏实际使用的位置。

## 4. 切换器安装与解压

预览分发提供 MSI 和便携 ZIP。GitHub 的“Source code”压缩包是源码，不是可直接运行的应用。两种运行包都需另装 Desktop Runtime，目前均未签名。

| 安装包 | 用途 |
| --- | --- |
| `SC2Switcher-3.4.2-x64.msi` | 需要管理员批准，为所有用户安装，创建一个共用开始菜单入口和全机卸载登记。 |
| `SC2Switcher-<version>-win-x64-preview.zip` | 解压到独立目录，不创建快捷方式或卸载登记。 |

MSI 安装要求切换器已关闭，并获得 Windows 管理员提示中的批准。程序安装到 `%ProgramFiles%\SC2RegionSwitcher\app`（64 位 Program Files）。开始菜单的 **SC2 Region Switcher** 入口以普通用户权限启动应用，每位用户分别保存配置。安装及全机维护需要管理员批准。

此前的 3.3.0 和 3.4.0 当前用户包属于内部预览。迁移过程包括在原安装用户的 Windows 会话中通过“已安装的应用”移除旧版，随后安装新 MSI。`%LOCALAPPDATA%\SC2RegionSwitcherV2` 目录必须保留，以供同一用户继续使用其中的配置与备份。这是一次性卸载重装；Windows Installer 无法跨当前用户与全机上下文执行大版本升级。新安装器检查发起安装的用户旧有的 HKCU App Paths 项，发现后会阻止安装并提示先移除旧版；它不扫描其他用户的配置。

后续全机版本在相同安装上下文中通过 MSI 大版本升级更新。3.4.1 的安装、恢复与 UAC 证据保留于[历史验证](VALIDATION-3.4.1.zh-CN.md)。安装失败后，错误详情与配置必须保留，以供诊断。

原始 3.3.0 安装器没有降级保护，不得覆盖较新安装。此前手动创建的快捷方式不由 MSI 管理。指向已退役版本的快捷方式需要经过目标核验，再对该快捷方式进行修正或移除。

便携部署采用完整 ZIP 解压，目标为独立目录，例如 `%LOCALAPPDATA%\Programs\SC2RegionSwitcher-Portable`。以下四个文件必须位于同一目录：

```text
SC2Switcher.Wpf.exe
SC2Switcher.Wpf.dll
SC2Switcher.Wpf.deps.json
SC2Switcher.Wpf.runtimeconfig.json
```

ZIP 另含英文和中文 README、`LICENSE`、双语第三方声明及 `licenses/` 目录，这些分发材料随解压包保留。应用入口为 `SC2Switcher.Wpf.exe`。可选快捷方式位于当前用户的开始菜单目录，该目录可通过 `Win + R` → `shell:programs` 访问。快捷方式目标为解压后的 EXE，起始位置为其所在目录。一个入口可用于两服选择。

## 5. 路径与界面语言配置

首次运行时，如果配置缺失或无效，程序会打开设置页。

| 设置项 | 选择内容 |
| --- | --- |
| 战网目录 | 直接包含 `Battle.net.exe` 的文件夹。 |
| 国服游戏目录 | 国服游戏根目录。 |
| 外服游戏目录 | 独立的国际服游戏根目录。 |
| 高级选项 → 共享游戏设置文件 | 实际的 `Variables.txt` 文件。 |

各位置可通过文件夹选择器或完整路径指定。路径框不会展开 `%USERPROFILE%` 等表达式。**保存并检查**操作验证路径、游戏分支、更新完成标记、语言声明和共享设置。无效输入不会替换已保存配置。保存成功后可返回主页面。

国服文本与语音使用 `zhCN`，国际服使用 `enUS`。设置页不提供自定义游戏语言组合。**界面语言**提供 **English** 和**简体中文**选项，语言选择立即生效并独立保存。新用户或无效语言偏好回退为英文，已有有效偏好会保留。

目录有未保存改动时，返回、按 Esc 或关闭窗口前需要保存或放弃。**放弃修改**恢复已保存路径。

## 6. 区域切换

1. 切换要求《星际争霸 II》和地图编辑器已关闭，且战网下载、更新和修复已完成。
2. 切换器中的本地安装检查必须通过。游戏更新后需要新的检查。
3. 目标为国服或国际服。国际服另需欧洲（`EU`）、美洲（`US`）或亚洲（`KR`）作为战网登录区域。
4. 切换操作依次执行战网退出、语言设置更新和目标登录区域启动。这些操作完成后才能再次切换。
5. 所需登录在战网中完成。游戏启动以安装位置核验和实际游戏服务器选择为前提。

操作期间相关控件和正常关闭窗口的功能会锁定，没有取消按钮。错误目标只能在当前操作完成后，通过另一次切换修正。战网提示需在战网中处理，切换器不会强制结束其进程。

**当前配置**来自战网的本地区域记录，**所选目标**是下一次请求切换的目的地。选择 EU、US 或 KR 不会立即改变当前区域显示，后者由程序读取到的状态更新。这些状态表示登录区域，不能确认账号已经登录，也不能确认《星际争霸 II》的游戏服务器。

## 7. 配置、备份与恢复

当前用户的数据保存在 `%LOCALAPPDATA%\SC2RegionSwitcherV2`：

| 文件或目录 | 用途 |
| --- | --- |
| `profiles.json` | 安装路径、游戏语言配置及国际服登录区域偏好 |
| `ui-preferences.json` | 界面语言 |
| `ConfigurationBackups` | 之前的配置文件 |
| `Backups` | 修改语言前保存的共享设置备份 |
| `pending-language.json` | 等待完成或恢复的语言事务 |
| `last-success.json`、`last-error.json` | 最近操作记录，不一定始终存在 |

卸载 MSI 时保留这些数据。移动或替换便携程序目录也不会移动它们。便携更新要求程序已关闭，新包解压到新目录，相关快捷方式随之更新。便携文件不得覆盖 MSI 管理的目录。

不存在用户配置时，程序可迁移应用旁有效的旧 `profiles.json`，同时保留原文件。换电脑后须重新核对路径。游戏移动后，战网对新位置的识别与核验必须先于切换器设置的修改。

未完成的语言事务要求保留原路径、配置、事务记录和备份。游戏与编辑器关闭、原配置通过安装检查后，使用原配置发起的后续切换会在开始阶段尝试恢复。仅打开窗口或执行检查不会触发恢复。再次恢复失败后，错误和文件必须保留以供诊断；事务记录不得删除，旧备份不得覆盖当前设置。

## 常见问题

| 现象 | 诊断或恢复要求 |
| --- | --- |
| 提示需要 .NET，或无法启动 | 启动要求 Desktop Runtime 10 x64 及完整的四个运行文件。 |
| 缺少游戏清单或分支错误 | 所选目录层级及战网中的区域安装需要核验，安装或修复必须完成。 |
| 缺少语言数据 | 所需语言的文本和语音必须通过战网安装。 |
| 缺少更新完成标记，或文件持续变化 | 新检查以战网更新或修复完成、完成标记已生成为前提。 |
| `Variables.txt` 缺失或无效 | 配置要求游戏实际使用的文件；文件缺失时，正常游戏会话及退出可生成该文件。 |
| 链接或重定向路径被拒绝 | 游戏和“文档”的实际位置需要核验；当前检查不支持重解析点路径。 |
| 游戏／编辑器运行中，或战网尚未退出 | 重试以正常退出及相关提示处理完成为前提。 |
| 无法确认目标登录区域 | 诊断依据包括战网登录界面和版本；启动器行为变化可能需要应用更新。 |
| 配置已被其他窗口修改 | 进一步编辑要求重复窗口已关闭，且应用已重新打开。 |
| 无法写入文件 | 诊断范围包括只读属性、当前用户权限及其他进程持有的文件锁。 |

两套游戏不必使用相同 build。官方更新后的兼容性取决于清单格式、路径和战网行为是否仍受支持。

诊断报告包含切换器、Windows、.NET 和战网版本、操作过程及完整错误文字。路径与日志片段的分发以个人信息审查为前提。报告以应用行为和脱敏后的诊断详情为限。已测范围与剩余限制见[验证记录](VALIDATION.zh-CN.md)。
