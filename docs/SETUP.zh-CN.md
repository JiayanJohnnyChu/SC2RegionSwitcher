# 配置与使用指南

SC2 Region Switcher 使用一套战网桌面应用和两套独立的《星际争霸 II》安装，切换战网登录区域并修改游戏共享设置中的语言键。当前开发版本为 3.4.1，需管理员权限的 MSI 已通过本地构建与包检查，CI 生命周期验收仍待完成。评估预览版前请参阅[验证状态](VALIDATION-3.4.1.zh-CN.md)。

## 1. 运行要求

- Windows x64 和 **Microsoft .NET 10 Desktop Runtime x64**。只有开发才需要 .NET SDK。请在 [Microsoft .NET 10 下载页](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)选择 Windows x64 的 **Desktop Runtime**。
- 一套官方 Battle.net 桌面应用，以及相应区域服务的访问条件。
- 独立安装的国服和国际服游戏，且下载、更新和修复均已完成。
- 游戏实际使用的 `Variables.txt`，当前 Windows 用户须能读写该文件。

切换器不下载游戏数据、不注册账号，也不改变账号使用资格。登录与身份验证在官方战网中完成。

## 2. 准备两套游戏安装

使用两个独立目录，例如：

```text
D:\Games\StarCraft II CN
D:\Games\StarCraft II Global
```

两者不能相同或互相包含。给同一安装换一个名字，或建立指向它的目录链接，都不构成第二套安装。每个游戏根目录须直接包含 `StarCraft II.exe`、`.build.info` 和 `Versions`。

在战网中为国际服安装英文文本与语音，为国服安装简体中文文本与语音。先准备哪一服均可。确认下载前核对最终安装位置：战网可能自动补上 `StarCraft II` 子目录，也可能识别已有安装。如果指向另一服的目录，应先修正位置再继续。

每套安装完成后，都通过战网启动游戏，确认能进入主界面，再正常退出。这也会生成共享设置文件。以后在切换器里修改路径，不会搬移游戏或更改战网的安装记录。

首次准备时若缺少所需的登录区域，先关闭游戏与编辑器，完成战网下载，再正常退出战网。下列 PowerShell 命令可请求同一程序使用指定登录区域；请换成实际路径，只执行需要的一条：

```powershell
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=CN
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=EU
```

其他国际登录区域值为 `US` 和 `KR`。打开后核对登录界面。当前实现使用此参数，兼容性取决于已安装的战网版本。如果参数不被接受，先通过战网解决区域访问问题。切换器会检查两套安装，无法替代这一步首次准备。

## 3. 找到共享设置文件

打开当前 Windows 用户实际的“文档”文件夹，找到：

```text
StarCraft II\Variables.txt
```

使用游戏生成的真实文件，其中应各有一条 `localeidassets` 和 `localeiddata`。找不到时，先运行游戏、保存设置并正常退出。新建空文件无法通过检查。

“文档”已移动时，可以在高级设置中选择真实文件位置。经过重解析点的路径会被拒绝，例如部分目录链接或同步文件夹。把文件复制到别处，并不能改变游戏实际使用的位置。

## 4. 安装或解压切换器

预览分发提供 MSI 和便携 ZIP。GitHub 的“Source code”压缩包是源码，不是可直接运行的应用。两种运行包都需另装 Desktop Runtime，目前均未签名。

| 安装包 | 用途 |
| --- | --- |
| `SC2Switcher-3.4.1-x64.msi` | 需要管理员批准，为所有用户安装，创建一个共用开始菜单入口和全机卸载登记。 |
| `SC2Switcher-<version>-win-x64-preview.zip` | 解压到独立目录，不创建快捷方式或卸载登记。 |

关闭切换器，运行 MSI，并批准 Windows 的管理员提示。程序安装到 `%ProgramFiles%\SC2RegionSwitcher\app`（64 位 Program Files）。从开始菜单正常打开 **SC2 Region Switcher** 即可；应用以普通用户权限运行，每位用户分别保存配置。安装及全机维护需要管理员批准。

此前的 3.3.0 和 3.4.0 当前用户包属于内部预览。迁移时，先登录当初安装预览版的 Windows 用户，在“已安装的应用”中卸载旧版，再运行新 MSI。保留 `%LOCALAPPDATA%\SC2RegionSwitcherV2`：配置和备份会保留，并由同一用户继续使用。这是一次性卸载重装；Windows Installer 无法跨当前用户与全机上下文执行大版本升级。新安装器检查发起安装的用户旧有的 HKCU App Paths 项，发现后会阻止安装并提示先移除旧版；它不扫描其他用户的配置。

后续全机版本在相同安装上下文中通过 MSI 大版本升级更新。新包的安装、维护及升级失败恢复仍待验收。安装失败时请保留错误详情和配置。

原始 3.3.0 安装器没有降级保护，不应在新版之上运行。此前手动创建的快捷方式不由 MSI 管理；若仍打开已退役版本，应核实目标后更新或移除那一个快捷方式。

使用便携 ZIP 时，将全部文件解压到独立目录，例如 `%LOCALAPPDATA%\Programs\SC2RegionSwitcher-Portable`。保持以下四个文件在同一目录：

```text
SC2Switcher.Wpf.exe
SC2Switcher.Wpf.dll
SC2Switcher.Wpf.deps.json
SC2Switcher.Wpf.runtimeconfig.json
```

当前 ZIP 另附英文和中文 README。运行 `SC2Switcher.Wpf.exe`。如需快捷方式，可通过 `Win + R` → `shell:programs` 打开当前用户的开始菜单目录，将快捷方式放入其中。目标设为解压后的 EXE，起始位置设为其所在目录。一个入口即可选择两服。

## 5. 配置路径与界面语言

首次运行时，如果配置缺失或无效，程序会打开设置页。

| 设置项 | 选择内容 |
| --- | --- |
| 战网目录 | 直接包含 `Battle.net.exe` 的文件夹。 |
| 国服游戏目录 | 国服游戏根目录。 |
| 外服游戏目录 | 独立的国际服游戏根目录。 |
| 高级选项 → 共享游戏设置文件 | 实际的 `Variables.txt` 文件。 |

可以浏览选择，也可以输入完整路径。路径框不会展开 `%USERPROFILE%` 等表达式。点击**保存并检查**，程序将检查路径、游戏分支、更新完成标记、语言声明和共享设置。无效输入不会替换已保存配置。保存成功后返回主页面。

国服文本与语音使用 `zhCN`，国际服使用 `enUS`。设置页不提供自定义游戏语言组合。在**界面语言**中选择 **English** 或**简体中文**，选择会立即生效并独立保存。新用户或无效语言偏好回退为英文，已有有效偏好会保留。

目录有未保存改动时，返回、按 Esc 或关闭窗口前需要保存或放弃。**放弃修改**恢复已保存路径。

## 6. 切换区域

1. 退出《星际争霸 II》和地图编辑器，等待战网下载、更新和修复结束。
2. 打开切换器，确认本地安装检查通过。游戏更新后重新检查。
3. 选择国服或国际服；国际服还需选择欧洲（`EU`）、美洲（`US`）或亚洲（`KR`）。
4. 开始切换，等待战网退出、语言设置更新和目标登录区域打开。
5. 在战网中完成所需登录，核对游戏安装位置，在那里选择实际游戏服务器，再启动游戏。

操作期间相关控件和正常关闭窗口的功能会锁定，没有取消按钮。选错目标时，等待本次完成再切换。战网提示需在战网中处理，切换器不会强制结束其进程。

**当前配置**来自战网的本地区域记录，**所选目标**是下一次请求切换的目的地。选择 EU、US 或 KR 不会立即改变当前区域显示，后者由程序读取到的状态更新。这些状态表示登录区域，不能确认账号已经登录，也不能确认《星际争霸 II》的游戏服务器。

## 7. 配置、备份与恢复

打开 `%LOCALAPPDATA%\SC2RegionSwitcherV2` 可查看当前用户的数据：

| 文件或目录 | 用途 |
| --- | --- |
| `profiles.json` | 安装路径、游戏语言配置及国际服登录区域偏好 |
| `ui-preferences.json` | 界面语言 |
| `ConfigurationBackups` | 之前的配置文件 |
| `Backups` | 修改语言前保存的共享设置备份 |
| `pending-language.json` | 等待完成或恢复的语言事务 |
| `last-success.json`、`last-error.json` | 最近操作记录，不一定始终存在 |

卸载 MSI 时保留这些数据。移动或替换便携程序目录也不会移动它们。更新便携版时，关闭程序，将新包解压到新目录，并更新快捷方式。不要用便携文件覆盖 MSI 管理的目录。

不存在用户配置时，程序可迁移应用旁有效的旧 `profiles.json`，同时保留原文件。换电脑后须重新核对路径。移动游戏后，先让战网识别并确认新位置，再修改切换器设置。

如果报告存在未完成的语言事务，请保留原路径、配置、事务记录和备份。关闭游戏与编辑器，原配置通过安装检查后，再发起一次切换。恢复发生在切换开始阶段；仅打开窗口或执行检查不会触发恢复。若再次失败，请保留错误和文件以供诊断，不要删除事务记录或用旧备份直接覆盖当前设置。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示需要 .NET，或无法启动 | 安装 Desktop Runtime 10 x64，并确认四个运行文件完整。 |
| 缺少游戏清单或分支错误 | 核对目录层级及战网中的区域安装，完成安装或修复。 |
| 缺少语言数据 | 在战网中安装所需语言的文本和语音。 |
| 缺少更新完成标记，或文件持续变化 | 让战网完成更新、修复并生成完成标记，再重新检查。 |
| `Variables.txt` 缺失或无效 | 选择实际文件；尚未生成时先正常运行并退出游戏。 |
| 链接或重定向路径被拒绝 | 核对游戏和“文档”的实际位置；当前检查不支持重解析点路径。 |
| 游戏／编辑器运行中，或战网尚未退出 | 正常关闭，处理相关提示后重试。 |
| 无法确认目标登录区域 | 查看战网登录界面和版本；启动器行为变化可能需要应用更新。 |
| 配置已被其他窗口修改 | 关闭重复的切换器窗口，重新打开再编辑。 |
| 无法写入文件 | 检查只读属性、当前用户权限及文件占用情况。 |

两套游戏不必使用相同 build。官方更新后的兼容性取决于清单格式、路径和战网行为是否仍受支持。

反馈时请提供切换器、Windows、.NET 和战网版本、操作步骤及完整错误文字。分享路径与日志片段前应检查其中的个人信息。报告以应用行为和脱敏后的诊断详情为限。已测范围与剩余限制见[验证记录](VALIDATION.zh-CN.md)。
