# 星际争霸 II 双服切换器

Windows 桌面工具，用于在同一台电脑上切换国服与国际服 Battle.net 登录区域，并同步《星际争霸 II》的共享游戏语言设置。界面基于 WPF，支持简体中文和 English。

本指南适用于 **3.3.0 预览版（Windows x64）**，核对日期为 **2026-09-21**。本版采用一套 Battle.net 桌面应用与两套独立游戏目录。账号认证、游戏下载、更新和游戏启动由官方战网完成。

> 使用前需要准备好两套完整游戏。当前语言规则为：国服简体中文，国际服英文。切换器负责检查和切换，不能代替游戏安装程序。

## 快速开始

如果两服已安装完成，可以按以下顺序配置：

1. 安装 **Microsoft .NET 10 Desktop Runtime，Windows x64**。
2. 确认两套游戏目录彼此独立，国服已安装简体中文文本与语音，国际服已安装英文文本与语音。
3. 至少正常启动并退出一次游戏，确认实际 Windows“文档”目录中已生成 `StarCraft II\Variables.txt`。
4. 使用当前用户安装包安装，从开始菜单打开 **SC2 Region Switcher**；也可使用便携 ZIP 运行文件。
5. 在设置页选择战网目录、国服目录、国际服目录；必要时在“高级选项”指定实际使用的 `Variables.txt`。
6. 点击“保存并检查”，通过后返回主页面，选择目标并执行切换。
7. 在打开的战网中完成登录，核对游戏位置与服务器后启动游戏。

尚未安装两服时，请先阅读下面的完整步骤。

## 1. 环境与前提

| 项目 | 要求 |
| --- | --- |
| 系统与架构 | 面向 Windows x64。建议使用仍受 Microsoft 支持的 Windows 11 x64 版本；其他 Windows 版本需同时满足 .NET 10 和游戏本身的要求。当前未验证 Windows on ARM、macOS 或 Linux。 |
| 运行环境 | .NET **Desktop Runtime 10.0.x x64**，选择最新稳定补丁版本。当前发布包不内置运行环境。 |
| 战网 | 已安装、可以正常打开并登录相应服务的官方 Battle.net 桌面应用。 |
| 游戏 | 两套完整安装，位于不同的实际本地目录。可以在同一磁盘，也可以在不同磁盘。 |
| 游戏语言 | 国服文本与语音为简体中文 `zhCN`；国际服文本与语音为英文 `enUS`。 |
| 账号与网络 | 能在官方战网分别完成国服与国际服登录；网络能够完成相应服务的认证、下载与更新。 |
| 文件权限 | 当前 Windows 用户能够读取安装文件、修改实际游戏设置文件，并写入自己的本地应用数据目录。 |

Windows 版本支持状态会变化，具体以 [Microsoft 的 .NET Windows 支持表](https://learn.microsoft.com/en-us/dotnet/core/install/windows#supported-versions)为准。本项目的验证范围不能替代 Microsoft 或游戏官方的系统支持范围。

切换器按普通桌面程序运行，不要求将“以管理员身份运行”设为默认。安装运行环境时，Windows 可能另行要求系统安装权限。请使用与日常运行战网和游戏相同的 Windows 用户配置本工具。

## 2. 安装正确的 .NET 运行环境

1. 打开 [Microsoft .NET 10 官方下载页](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)。
2. 找到 **.NET Desktop Runtime 10.0.x**，在 **Windows / Installers** 中选择 **x64**。
3. 运行下载的安装程序，完成后重新打开切换器。

请保留名称中的 **Desktop**。单独安装普通“.NET Runtime”、ASP.NET Core Runtime、.NET Framework 4.x，或只安装 x86 / Arm64 版本，不能满足本 x64 WPF 程序的依赖。普通用户无需安装开发用 SDK。Desktop Runtime 已包含所需的基础 .NET Runtime，下载页对此有说明。

<details>
<summary>可选：使用命令安装或检查运行环境</summary>

已安装 WinGet 的用户可以在 PowerShell 中运行以下安装命令。安装时按 Windows 提示完成授权：

```powershell
winget install --id Microsoft.DotNet.DesktopRuntime.10 --exact --architecture x64
```

该包标识见 [Microsoft 的 WinGet 安装说明](https://learn.microsoft.com/en-us/dotnet/core/install/windows#install-with-windows-package-manager-winget)。

使用默认安装位置时，可以检查 x64 运行环境：

```powershell
& "$env:ProgramFiles\dotnet\dotnet.exe" --list-runtimes
```

输出中应包含 `Microsoft.WindowsDesktop.App 10.0.` 开头的版本。如果只是找不到 `dotnet` 命令，先使用上面的完整路径，或重新打开终端；不要据此直接断定 Desktop Runtime 未安装。

</details>

## 3. 准备战网和两套游戏

### 3.1 获取官方安装程序

可从 [国服《星际争霸 II》官网](https://sc2.blizzard.cn/)进入国服下载入口，或从 [Battle.net 官方下载页](https://download.battle.net/en-us/)获取桌面应用。本方案使用一套战网桌面应用。

在相应登录区域登录后，进入战网中的《星际争霸 II》页面完成安装。国服官方提供过[通过战网安装游戏的说明](https://sc2.blizzard.cn/news/24172797/index.html)；战网界面的名称和位置可能随更新调整，以实际界面为准。

账号绑定、账号恢复、密码和验证码均在官方界面中处理。切换器没有代为登录的功能，也不提供填写账号密码的入口。

### 3.2 先确定两套独立目录

下面只是目录示例，可替换为自己的磁盘和文件夹：

```text
D:\Games\
├── StarCraft II CN\
│   ├── StarCraft II.exe
│   ├── .build.info
│   ├── .patch.result
│   ├── SC2Data\
│   └── Versions\
└── StarCraft II Global\
    ├── StarCraft II.exe
    ├── .build.info
    ├── .patch.result
    ├── SC2Data\
    └── Versions\
```

国服与国际服目录不能相同，也不能一个位于另一个内部。例如，将国际服放在 `D:\Games\StarCraft II CN\Global` 不符合要求。磁盘空间以战网显示的两套安装大小及更新所需空间为准。

本版接受带盘符的完整本地路径，不接受网络共享路径或磁盘根目录作为安装目录，并会拒绝经过符号链接、目录联接或其他重解析节点的受检查路径。请使用实际目录，不要通过链接让两服共享游戏数据。

已有其中一服时，可以保留它，给另一服新建独立安装目录。若已有一份曾被两服交替更新的共享目录，应先在战网中确认和修复其所属版本，再单独安装缺少的一服。

### 3.3 在战网中安装国际服与国服

先安装哪一服均可。以下按国际服在先说明：

1. 在战网登录界面选择国际登录区域，登录可用于国际服务的账号。
2. 打开《星际争霸 II》页面，安装到预留的国际服目录。已经安装时，核对战网识别的位置即可。
3. 在游戏的安装或语言设置中选择英文文本与英文语音，等待下载、更新及必要的修复全部结束。
4. 通过战网启动国际服，确认可以正常进入游戏，再正常退出。
5. 切到中国登录区域，按官方界面完成国服账号登录。
6. 安装国服时，显式选择另一套目录，并安装简体中文文本与语音。先核对目录，再确认安装。
7. 等待安装、更新完成，通过战网启动国服并正常退出。

**每次都核对战网显示的实际安装位置。** 安装界面可能自动补上一层 `StarCraft II` 文件夹；切换器需要的是最终包含 `StarCraft II.exe` 和 `.build.info` 的目录，而不一定是安装时最初选择的父目录。

如果战网自动识别到了另一服的文件夹，请先修正其安装或定位位置，再继续下载。以后在切换器里修改路径，仅改变本工具的配置，不会替你调整战网的安装记录。

<details>
<summary>首次安装时，战网登录页没有所需区域选项</summary>

先退出游戏和地图编辑器，完成战网中的下载或更新，再从战网菜单正常退出桌面应用。此时可以尝试按指定区域打开同一个战网程序。

在 PowerShell 中，以下示例打开中国登录区域：

```powershell
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=CN
```

以下示例打开欧洲登录区域：

```powershell
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=EU
```

请把可执行文件路径替换为自己的实际位置。国际登录区域还可使用 `US`（美洲）或 `KR`（亚洲）。一次选择一个目标，打开后核对登录界面。

`--setregion` 是本工具当前实现及本机验证使用的启动参数，不能视为战网官方承诺长期保持的接口。若当前战网版本不接受参数或没有进入预期区域，请停在安装准备阶段，使用官方入口或支持渠道确认区域登录方式。此时不要让两服指向同一目录来绕过问题。

本版切换器必须先通过两套安装的检查，因而不能用“先在切换器里选另一服”的方法代替上述首次安装准备。

</details>

### 3.4 确认游戏语言数据

当前预设如下：

| 安装 | 文本 | 语音 |
| --- | --- | --- |
| 国服 | 简体中文 `zhCN` | 简体中文 `zhCN` |
| 国际服 | English `enUS` | English `enUS` |

国际服无需为本工具额外下载中文语言包，但英文文本和英文语音都要安装完成。切换器会读取游戏安装清单检查语言声明，无法代替战网补齐缺失资源。

界面语言与上述规则相互独立：把切换器界面改成中文，不会把国际服游戏改成中文。当前设置页不提供自定义游戏语言组合。

### 3.5 确认实际使用的 Variables.txt

游戏通常将共享设置保存到当前 Windows 用户的“文档”目录：

```text
文档\StarCraft II\Variables.txt
```

请在文件资源管理器中打开实际“文档”位置，进入 `StarCraft II` 文件夹查找。文件应由游戏正常运行后生成，不要为了通过检查而新建空文件。

如果找不到，先确认当前 Windows 用户，再通过战网启动游戏、完成一次正常设置保存并退出。该文件需要能正确读取，并包含各一条 `localeidassets` 与 `localeiddata` 语言设置。

“文档”重定位到其他普通本地目录时，可在切换器的高级选项中选择真实文件。OneDrive、同步盘或链接目录中的路径可能包含重解析节点，当前版本会拒绝这类路径；仅把设置文件复制到别处再选中副本，无法改变游戏实际读写的位置。

## 4. 解压并配置切换器

### 4.1 选择安装包或便携包

从项目发布者提供的发布附件中下载 Windows x64 包。在 GitHub 上应选择 Releases 中的运行附件；“Source code”压缩包属于源码，不能直接当作已编译程序运行。

| 形式 | 文件 | 适用方式 |
| --- | --- | --- |
| 当前用户安装包 | `SC2Switcher-3.3.0-current-user.msi` | 通过 Windows Installer 登记程序，并创建一个开始菜单入口。 |
| 便携包 | `SC2Switcher-3.3.0-win-x64-preview.zip` | 完整解压后直接运行；快捷方式由使用者自行设置。 |

日常使用推荐当前用户安装包。先完成第 2 节的运行环境准备，再运行 MSI；本包不附带 .NET 运行环境。安装位置为 `%LOCALAPPDATA%\Programs\SC2RegionSwitcher\3.3.0`，开始菜单中的名称为 **SC2 Region Switcher**。可以搜索这个名称或 `SC2`，国服与外服均在同一个主窗口选择。安装包只创建这一项菜单入口，不创建桌面入口。

安装包会在 Windows 的“已安装的应用”中登记 **SC2 Region Switcher**，可通过该条目卸载。安装文件与第 6 节的用户配置、备份目录分开管理。当前安装包仍是未签名的预览版，已完成本机当前用户安装验证，跨电脑与不同系统策略环境仍需验证。

选择便携包时，解压到独立文件夹后，应保留以下文件在同一目录：

```text
SC2Switcher.Wpf.exe
SC2Switcher.Wpf.dll
SC2Switcher.Wpf.deps.json
SC2Switcher.Wpf.runtimeconfig.json
```

说明文件可能随包附带。请完整解压后运行 `SC2Switcher.Wpf.exe`，不要只复制其中的 `.exe`。便携 ZIP 不会自动创建快捷方式；希望手动添加开始菜单入口时，可按下一节设置。

### 4.2 便携包：手动设置单一开始菜单入口

已经使用 MSI 的用户可以跳过本节。便携部署也可以将程序保存在当前用户的程序目录中，桌面无需放置启动入口。建议目录如下，在文件资源管理器地址栏中可使用 `%LOCALAPPDATA%`：

```text
%LOCALAPPDATA%\Programs\SC2RegionSwitcher\3.3.0
```

1. 新建上述目录，将完整的运行文件放入其中。
2. 为其中的 `SC2Switcher.Wpf.exe` 创建一个快捷方式，命名为 **SC2 Region Switcher**。
3. 按 `Win + R`，输入 `shell:programs` 并回车，打开当前用户的开始菜单“程序”文件夹。
4. 在该文件夹中建立 `SC2 Region Switcher` 程序组，将这一个快捷方式放入其中。快捷方式目标为实际 `.exe`，启动参数留空，起始位置设为程序所在文件夹。
5. 打开开始菜单，搜索“SC2 Region Switcher”，或从应用列表中打开它。

国服与外服均在同一个主窗口选择，因此只需一个入口。若此前在桌面放置过本工具的旧入口，先核对名称和目标并备份，再移出桌面；官方游戏自身的快捷方式与本工具入口不同。

上述手动方式不会额外注册 Windows“已安装的应用”卸载项。程序的位置与配置位置相互独立，原有用户配置仍从第 6 节的数据目录读取。若手动入口未被 Windows 收录，可改用当前用户 MSI；无需修改开始菜单祖先目录或其他应用的权限来排查。

### 4.3 填写设置页

首次运行且没有用户配置时，会自动进入设置页。以后可以通过主页面的“设置 / Settings”进入。

| 设置项 | 应选择的内容 | 核对方法 |
| --- | --- | --- |
| 战网目录 / Battle.net folder | 包含 `Battle.net.exe` 的文件夹 | 选择安装根目录，不要选择开始菜单快捷方式或某个版本子目录。 |
| 国服游戏目录 / China game folder | 国服游戏根目录 | 直接包含 `StarCraft II.exe`、`.build.info` 和 `Versions`。 |
| 外服游戏目录 / Global game folder | 国际服游戏根目录 | 与国服目录独立；确认没有多选或少选一层目录。 |
| 高级选项 → 共享游戏设置文件 | 实际的 `Variables.txt` 文件 | 此处选择文件，其余三项选择文件夹。 |

每项支持手动输入或点击“浏览 / Browse”。手动输入完整路径，例如 `D:\Games\StarCraft II CN`；输入框不会自动展开 `%USERPROFILE%` 等环境变量表达式。

点击 **“保存并检查 / Save and check”**。程序会检查路径、安装分支、更新完成标记、语言声明及共享设置文件。通过后会显示目录已保存的提示，再点击“返回切换 / Back to switching”。

检查失败时，按提示修正对应字段后重新保存。无效候选不会覆盖原有配置。存在未保存的目录编辑时，返回、Esc 或关闭窗口都会要求先保存或放弃；“放弃修改 / Discard changes”恢复已保存的目录。

界面语言在此页面即时切换并单独保存，无需点击目录的保存按钮。

## 5. 日常切换

1. 退出《星际争霸 II》和地图编辑器，确认战网中的下载、安装、更新或修复已结束。
2. 打开切换器，确认“本地安装检查通过”。如果刚完成更新，执行“重新检查”。
3. 选择国服或外服。选择外服时，再选择欧洲、美洲或亚洲登录区域。
4. 执行切换，等待战网退出、语言设置同步和目标区域重新打开。
5. 在战网中完成可能需要的账号登录，核对《星际争霸 II》的安装位置，并按需要选择游戏服务器，再点击开始游戏。

切换期间相关控件会锁定，窗口不能正常关闭，也没有取消按钮。选错目标时，等待本次操作结束后再切换。若战网自身弹出下载确认等提示，先在战网中处理；切换器不会强制结束战网进程。

外服的欧洲、美洲、亚洲选项用于 **Battle.net 登录区域**，不代表更改账号注册国家，也不保证已经选定游戏内服务器。Blizzard 的 [Global Play 说明](https://news.blizzard.com/en-us/article/8953701/global-play-is-now-live)讨论的是中国以外的游戏区域切换；本工具还要处理独立的国服安装和共享语言设置。

### 如何理解界面状态

| 状态 | 含义 |
| --- | --- |
| 战网当前配置 | 从本地战网配置读取的登录区域，不表示账号已经登录。 |
| 本地安装检查通过 | 本地文件满足当前检查条件，不表示服务器可连接或账号认证已完成。 |
| 已打开国服 / 外服战网 | 已请求启动目标战网，并观察到相符的区域记录；还需要在战网中确认登录与游戏启动。 |
| 安装检查未通过 / 操作未完成 | 查看错误详情，按原因修正后重新检查。失败后也应核对战网实际显示的登录区域。 |

首次配置后的完整验收是：两服各完成一次“切换 → 登录战网 → 进入游戏主界面 → 正常退出”。其中需要账号认证的步骤由使用者在官方界面中完成。

## 6. 配置、备份与升级

在文件资源管理器地址栏输入以下位置，可以查看当前用户的数据目录：

```text
%LOCALAPPDATA%\SC2RegionSwitcherV2
```

| 文件或目录 | 内容 |
| --- | --- |
| `profiles.json` | 安装位置、游戏语言配置和外服登录区域偏好。 |
| `ui-preferences.json` | 简体中文或 English 的界面语言偏好。 |
| `ConfigurationBackups` | 替换现有安装配置前保存的原文件。 |
| `Backups` | 修改共享游戏语言前保存的 `Variables.txt` 备份。 |
| `pending-language.json` | 尚未完成提交或恢复的语言切换记录；正常完成后会移除。 |
| `last-success.json` / `last-error.json` | 最近一次切换成功记录或错误信息；不一定始终存在。 |

配置按 Windows 用户保存，程序目录里不需要预置个人路径。数据目录名称保留了 `V2`，这是现有版本沿用的数据位置。

便携版升级时，先关闭切换器，将新运行包解压到新的独立目录，再启动新版本；同时更新原有快捷方式的目标、起始位置和图标位置，使其指向新版本，继续保留一个入口。

使用当前预览版 MSI 时，请保留安装包，按后续版本的升级说明操作。本版尚未提供自动升级流程；更换不同版本的安装包前，先正常退出程序并卸载旧程序，再安装新版。卸载范围为本安装包登记的程序文件、菜单入口与应用登记，不包含第 6 节的用户配置和语言备份。不要通过直接覆盖 MSI 管理的程序目录来升级。

使用同一 Windows 用户时，新版本仍会读取原有用户配置。

当前版本在没有用户配置、但程序旁存在旧 `profiles.json` 时，会尝试校验并迁移该文件；原文件保留。失效配置会进入设置页供修正。将程序复制到另一台电脑后，应重新选择那台电脑的实际安装位置。

移动游戏前应结束游戏与更新任务；移动后先让战网重新识别并确认安装，再到切换器中更新路径。当前保存目录功能本身不执行游戏搬移。

## 7. 常见问题

| 现象或提示 | 检查与处理 |
| --- | --- |
| 打开时提示需要安装或更新 .NET | 安装 .NET **Desktop Runtime 10.0.x x64**，并确认四个运行文件完整。安装了其他主版本或架构不等于已满足依赖。 |
| 找不到 `Battle.net.exe` | 选择实际战网安装目录。常见位置为 `C:\Program Files (x86)\Battle.net`，但应以本机为准。 |
| 缺少版本清单或安装文件不完整 | 核对游戏根目录层级，在战网中完成安装或扫描修复。 |
| 国服与外服目录不能相同或互相包含 | 选择两套独立安装。仅给同一安装改名或建立目录链接不能构成两套安装。 |
| 目录中的版本分支不正确 | 可能两服路径填反，或该目录曾被另一服更新。先在战网中核对对应安装并修复。 |
| 未声明已安装所选语言 | 在战网中补齐国服简体中文或国际服英文的文本与语音，等待下载完成再检查。 |
| 缺少成功完成更新的标记 / 游戏文件正在变化 | 让战网完成更新或修复，再重新检查。不要手动伪造 `.patch.result` 或修改 `.build.info` 来跳过检查。 |
| 找不到 `Variables.txt`，或语言键缺失、重复 | 使用正确 Windows 用户，通过战网运行游戏、保存语言相关设置并正常退出；选择实际生成的文件。若仍失败，保留文件并反馈错误，不要用空白文件替代。 |
| 路径经过链接或重定向 | 当前检查拒绝相应重解析路径。确认实际安装及实际文档位置；同步盘和链接目录暂不保证兼容。 |
| 检测到游戏或编辑器正在运行 | 正常退出游戏及地图编辑器后重新检查。 |
| 战网尚未退出 | 处理战网提示，再从其菜单正常退出后重试。 |
| 战网收到启动请求，但区域未能确认 | 检查实际登录界面和战网版本。可能需要适配新的战网行为，不应把该提示直接理解为账号密码错误。 |
| 配置已被其他窗口修改 | 关闭多余切换器窗口，重新打开程序以读取最新配置，再编辑保存。 |
| 无法写入配置或共享设置 | 核对文件只读状态、当前用户权限及文件是否被占用。若 Windows 给出具体拦截通知，先核实对应文件和应用；无需为排查而关闭系统保护。 |
| 游戏更新后不再通过检查 | 先完成更新并重新检查。若提示清单格式变化，保留错误信息，等待或反馈给项目维护者进行适配。 |

### 存在未恢复的切换记录

出现该提示时，先保留原安装路径、原用户配置以及 `pending-language.json` 和备份文件。退出游戏与编辑器，在原配置通过安装检查后再次发起切换；程序会在切换流程开始时尝试恢复上次的语言修改。**单纯打开窗口或点击重新检查不会触发这项恢复。**

如果恢复再次失败，或游戏设置在中断后发生了其他变化，请保留现场并反馈错误。不要通过删除待恢复记录或用旧备份直接覆盖当前游戏设置来跳过检查。

### 游戏更新后是否需要重新安装切换器

本版读取实际安装清单，不要求游戏始终保持某个固定 build，也不要求国服和国际服的 build 完全相同。两套路径、清单格式和战网区域行为保持兼容时，可以在官方更新完成后继续检查和使用。

这不构成对未来更新的兼容保证。战网启动参数、本地配置结构、游戏清单格式或路径结构发生变化时，切换器可能需要更新。本工具对安装文件活动的观察也不能代替战网自身的下载状态。
