# 配置与使用指南

SC2 Region Switcher 使用一套战网和两套独立的《星际争霸 II》安装，切换战网登录区域及游戏共享语言设置。

下载见 [v3.5.3-preview.1](https://github.com/JiayanJohnnyChu/SC2RegionSwitcher/releases/tag/v3.5.3-preview.1)。应用支持十一种界面语言。国服使用简体中文文字与语音，国际服使用所选的已安装文字与语音资源对。

## 1. 下载与安装

应用需要 Windows x64 和 **Microsoft .NET 10 Desktop Runtime x64**，可从 [Microsoft .NET 10 下载页](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)获取。日常使用不需要 SDK。安装包未签名。

| 下载 | 安装与启动 |
| --- | --- |
| `SC2Switcher-3.5.3-x64.msi` | 安装要求切换器已关闭，并获得管理员批准。它为所有 Windows 用户安装，创建 **SC2 Region Switcher** 开始菜单入口。应用以普通用户权限运行。 |
| `SC2Switcher-3.5.3-win-x64-preview.zip` | 完整解压到独立目录后即可使用便携应用，入口为 `SC2Switcher.Wpf.exe`，不创建快捷方式或 Windows 卸载登记。 |

GitHub 的 **Source code** 压缩包包含源码，不是可直接运行的应用。便携解压保留全部附带文件，包括以下四个运行文件，以及声明和许可证：

```text
SC2Switcher.Wpf.exe
SC2Switcher.Wpf.dll
SC2Switcher.Wpf.deps.json
SC2Switcher.Wpf.runtimeconfig.json
```

可选的便携快捷方式以解压后的 EXE 为目标、所在目录为起始位置。一个应用入口即可用于两套游戏安装。

## 2. 战网中的准备

准备工作要求能够访问相应区域服务，并完成两套游戏安装。切换器不下载游戏文件、不注册账号，也不改变账号使用资格。

两套安装使用独立目录，例如：

```text
D:\Games\StarCraft II CN
D:\Games\StarCraft II Global
```

两个目录不能互相包含。同一安装的两个名称或目录链接不构成两套安装。所选游戏根目录直接包含 `StarCraft II.exe`、`.build.info` 和 `Versions`。

**即使战网显示“安装”，也需要核对最终安装位置。** 启动器可能在所选路径后补上 `StarCraft II` 子目录，或识别另一套安装。确认安装前显示的位置必须对应预期的独立游戏根目录，不能指向另一服的目录内部。

国服需要简体中文文字和语音。国际服需要所选语言的文字和语音资源齐全。资源通过战网安装。切换器中出现某种语言，不代表正在进行的下载已经完成。

每套安装完成后，通过战网启动、到达游戏主界面并正常退出即可进行基本检查，同时生成共享设置文件。在切换器中改变路径不会搬移游戏文件，也不会更改战网的安装记录。

### 可选的登录区域准备

准备以常规战网操作为主。如果所需登录区域不可用，下列 PowerShell 命令可分别向同一战网程序请求登录区域。示例路径必须与实际安装一致。前提是游戏与编辑器已关闭、下载已完成、战网已正常退出。

```powershell
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=CN
& 'C:\Program Files (x86)\Battle.net\Battle.net.exe' --setregion=EU
```

仅所需区域的命令适用，其他国际服取值为 `US` 和 `KR`。请求后的战网登录界面用于确认区域。支持情况取决于战网版本；请求不被接受时，战网区域访问仍需在配置切换器前解决。

## 3. 首次配置

配置缺失或无效时，应用打开设置页。下列路径仅为示例，各字段需对应电脑上实际使用的位置。

| 设置项 | 所需位置 | 示例 |
| --- | --- | --- |
| 战网目录 | 直接包含 `Battle.net.exe` 的文件夹 | `C:\Program Files (x86)\Battle.net` |
| 国服游戏目录 | 国服游戏根目录 | `D:\Games\StarCraft II CN` |
| 外服游戏目录 | 独立的国际服游戏根目录 | `D:\Games\StarCraft II Global` |
| 共享游戏设置文件 | 游戏实际“文档”位置中的 `Variables.txt` | `D:\Documents\StarCraft II\Variables.txt`，仅适用于“文档”位于此处的情况 |

文件字段位于**高级 · 共享游戏设置**。文件夹／文件按钮和完整路径均可指定位置；手工输入的路径不会展开 `%USERPROFILE%` 等表达式。

共享文件通常为当前 Windows 用户实际“文档”文件夹下的 `StarCraft II\Variables.txt`。“文档”移动后，以真实位置为准。文件须由游戏生成，并包含 `localeidassets` 和 `localeiddata` 语言项。缺失时，一次保存设置并正常退出的游戏会话会生成它。空白文件或其他位置的副本不能替代游戏实际使用的文件。

当前路径检查拒绝经过目录链接和其他重解析点的路径，包括部分重定向或同步文件夹。检查依据是实际位置及访问情况，而不只是显示的文件夹名称。

**保存并检查**验证并保存配置。无效输入不会替换原配置，单独保存也不会写入游戏语言设置。有未保存修改时，返回、按 Escape 或关闭窗口前需要保存或**放弃修改**。

## 4. 区域切换

1. 《星际争霸 II》和地图编辑器已关闭，战网下载、更新和修复已完成。
2. 切换器中的安装检查通过，游戏更新后需要重新检查。
3. 目标为国服或国际服；国际服另选欧洲（`EU`）、美洲（`US`）或亚洲（`KR`）作为战网登录区域。
4. 切换操作请求战网正常退出，备份并修改游戏语言设置，再以所选区域启动战网。
5. 所需登录在战网中完成，游戏启动以正确安装位置及实际游戏服务器的选择为前提。

操作结束前，相关控件和正常关闭窗口功能保持锁定。界面没有取消按钮，其他目标可在本次完成后再请求。战网提示在战网中处理，切换器不会强制关闭它。

**登录区域与游戏服务器是两个独立选择。** EU、US 和 KR 表示战网登录区域。选择目标不会立即改变当前区域读数，本地区域记录也不能证明账号已登录或已选择相应《星际争霸 II》服务器。

界面在观察到区域、文字语言和语音语言均与目标一致时禁用操作按钮。待恢复或未知状态另行处理。

## 5. 界面与游戏语言

界面语言只改变切换器的文字，立即生效并在下次启动时保留，不改变两套游戏的语言。

**外服游戏语言（实验性）**为文字和语音统一选择语言，列表包含安装中同时声明具备这两类资源的语言。其他资源需要通过战网安装。

打开设置或完成外服路径编辑后开始检测，**重新检测**可再次检查。磁盘不可用、更新未完成或语言资源缺失时，选择器可能禁用，但保留原偏好。路径改变后，先保存并检查新目录，才能选择其中的语言。

语言选择在**保存并检查**成功前属于草稿，只在后续切换时应用。旧配置中不同的文字与语音组合会保留，直到选择统一语言。**放弃修改**恢复已保存路径和语言组合。待恢复事务须使用原配置完成恢复，之后才能修改游戏语言。

## 6. 存档、备份与恢复

切换器只修改游戏共享设置文件中的 `localeidassets` 和 `localeiddata`，不复制、删除或管理战役存档、录像及 `Accounts` 文件，也不在区域或账号之间转移进度。进度的可用范围由游戏账号和区域决定，切换器不提供云存档同步。

**游戏语言设置备份不等于战役存档备份。** 它保留的是语言修改前的共享设置。切换器数据另存于 `%LOCALAPPDATA%\SC2RegionSwitcherV2`：

| 文件或目录 | 内容 |
| --- | --- |
| `profiles.json` | 安装路径、游戏语言配置及国际服登录区域偏好 |
| `ui-preferences.json` | 界面语言 |
| `ConfigurationBackups` | 较早的切换器配置 |
| `Backups` | 游戏共享设置备份 |
| `pending-language.json` | 等待完成或恢复的语言修改 |
| `last-success.json`、`last-error.json` | 最近操作记录，不一定始终存在 |

未完成的操作要求保留原路径、配置、恢复记录及备份。游戏和编辑器关闭、原安装配置通过检查后，后续切换会先尝试恢复，再进行新的语言修改。仅打开应用或执行检查不会开始恢复。

再次恢复失败时，错误和文件需要保留以供诊断。删除恢复记录，或用旧备份覆盖当前设置，可能移除恢复所需的信息。

## 7. 更新、卸载与游戏搬移

MSI 更新使用较新安装器，切换器须已关闭。卸载入口位于 Windows“已安装的应用”，卸载后保留 `%LOCALAPPDATA%\SC2RegionSwitcherV2` 中的设置与备份。

便携更新时，应用已关闭，新 ZIP 解压到新目录，相关快捷方式改为新位置。便携文件不应放入由 MSI 管理的应用目录。移除便携应用目录不会移除独立保存的设置。

较早的单用户预览版需由原安装用户先卸载，再进行当前的全用户安装，这项迁移仅需一次。保留独立数据目录即可保留该用户的配置与备份。旧 3.3.0 安装器不适合覆盖较新版本。

游戏搬移后，战网需要先识别并检查新位置，之后才修改切换器中的对应路径。已有快捷方式可能仍指向旧切换器目录。没有当前配置时，应用旁有效的旧 `profiles.json` 可以导入，原文件保留。

## 8. 常见问题

| 现象 | 说明或下一步检查 |
| --- | --- |
| 应用无法启动或提示需要 .NET | 需要 Desktop Runtime 10 x64 及四个完整运行文件。 |
| 缺少游戏文件或区域错误 | 路径须直接指向预期游戏根目录，安装或修复已完成。 |
| 语言不可用 | 文字和语音均需通过战网安装，完成后再进行语言检测。 |
| 提示更新未完成 | 战网完成下载、更新或修复后，才能重新检查。 |
| `Variables.txt` 缺失或无效 | 需要游戏实际生成并使用的文件。缺失时，正常游戏会话和退出可生成它。 |
| 链接或重定向路径被拒绝 | 当前检查不支持重解析点路径，需要核对游戏真实目录及“文档”位置。 |
| 游戏／编辑器仍运行，或战网未退出 | 再次尝试要求相关程序正常退出，且战网提示已处理完成。 |
| 无法确认登录区域 | 战网登录界面及版本有助于定位问题，启动器更新可能改变支持情况。 |
| 配置在另一窗口中改变 | 继续编辑需要关闭重复的切换器窗口，再重新打开应用。 |
| 文件无法写入 | 只读属性、当前用户权限或其他程序的文件锁都可能阻止写入。 |

两套游戏不必使用相同版本号，但官方更新仍可能影响兼容性。问题报告包含切换器、Windows、.NET 和战网版本、操作步骤及错误文字，并移除个人路径和账号信息。
