# 界面设计与本地化

界面采用原生 WPF。主页面分别显示战网当前本地配置、所选目标和操作结果。3.4.1 的国际服目标卡片使用 EU、US 或 KR 标示所选登录区域，国服使用 CN。游戏服务器仍在战网中选择。

## 语言行为

- 缺失、不可读或不受支持的偏好回退到 `en-US`；有效的 `en-US` 和 `zh-CN` 偏好会保留。
- 设置页即时应用并保存界面语言，路径改动则需点击**保存并检查**。
- 界面语言独立于国服 `zhCN` 和国际服 `enUS` 游戏语言配置。
- 英文使用 Segoe UI，中文使用 Microsoft YaHei UI，中文展示标题使用常规字重。
- 两份 JSON 资源的键和格式占位符一致，由回归程序检查。

## 布局与颜色

国服和国际服目标并排显示。选中卡片使用实心区域色、不透明白字和勾选标记；未选卡片的小标签与选择圆环保留区域色。国际服区域控件位于卡片下方，共用基线。主操作始终位于底部可见位置。

设置页和参考页共用页面底色、字体、分隔线与页脚对齐。较长的表单与参考内容可滚动，底部操作固定。紧凑布局保留两服目标、全部三个国际登录区域和主操作，窄窗口通过文字换行适配。

颜色定义在 `src/SC2Switcher.Wpf/Palette.xaml`，由 `App.xaml` 合并。sRGB 数值来自 [Radix Colors](https://github.com/radix-ui/colors/blob/main/src/light.ts)，在应用中的角色分配由本项目定义。程序不包含 Radix 框架或网页运行环境。

白字与 Tomato 11 的对比度约为 4.98:1，与 Indigo 9 约为 5.21:1。忙碌时选中标签及其父卡片仍完全不透明。这些数值只描述相应颜色组合，不代表整款应用已达到某项无障碍标准。

## 状态与交互

`CurrentLoginRegion` 通过 `SetCurrent` 更新。选择目标、修改国际区域偏好或切换界面语言，不会改变当前配置标记的颜色。未知当前区域使用中性色。状态信息同时使用文字符号和颜色。

检查和切换时禁用相关操作，不提供取消按钮。设置未保存时，返回、Esc 和关闭窗口会要求保存或放弃。保存期间锁定路径、语言及导航控件；无效输入不会改变已保存配置。从参考页返回时恢复键盘焦点，错误详情完整保留且可选择复制。

## 诊断与覆盖范围

`--ui-report <绝对JSON路径>` 输出布局数据及 WPF 自渲染图。F12 捕获当前页面，`--compact` 请求最小尺寸。存在绑定错误时，日志保存在报告旁。

`--matrix` 导出两种语言的正常、窄窗口、忙碌、错误、成功、设置、未保存编辑及参考状态。它要求显式指定独立的 `--data-dir`，展示期间禁用真实切换和路径保存。模拟报告标记 `SyntheticState=true`。

DPI 验证要求通过 EXE 启动应用，以使其 PerMonitorV2 清单生效。自渲染与外部窗口截图属于不同观察结果。原始图片和报告保存在 Git 忽略的 `artifacts/` 目录。

完整的 100%、125%、150% 和 200% 双语矩阵属于原始 3.4.0 候选。较早的 3.4.1 测试覆盖标准窗口在 200% 下的基本双语标签检查。最终已安装候选另通过隔离配置下的基本英文和简体中文设置界面检查，截图与辅助功能树显示控件完整，未观察到裁切。DPI 矩阵未重复执行。跨显示器移动和跨电脑行为尚未验证。证据记录于[验证记录](VALIDATION.zh-CN.md)。
